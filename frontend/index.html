AMMO Guide

A What is AMMO?

AMMO (Agentic Model-on-Machine Optimizer) provides AI-assisted optimization of vLLM's GPU kernels for any supported model. Each session gives you a Claude Code environment with full vLLM access on H200 GPUs.

6-Stage Pipeline

1
Baseline Capture
Profile vLLM end-to-end with nsys & ncu
2
Bottleneck Mining
Identify highest-impact optimization targets
3
Candidate Proposal
Team-based adversarial debate on strategies
4
Implementation
Optimize in isolated vLLM worktree
5
Validation
Correctness checks & micro-benchmarks
6
Integration
Validate end-to-end throughput gains

Session Lifecycle

CREATE → ACTIVE ↔ PAUSED → TERMINATED
Active — Claude Code running, GPU allocated
Paused — State saved to S3, GPUs released
Resume — Claude auto-continues with --continue flag
Inactivity — Auto-pauses after 60 min idle

Quick Tips

  • • Open up to 2 terminals side-by-side by clicking active sessions
  • • Click any session ID to copy it to clipboard
  • • Use TP=1 for small models, TP=8 for large MoE models like DeepSeek-R1
  • • Pause before leaving — S3 sync preserves your entire session
  • • Use /ui#session/<id> URLs to share direct session links
  • • Check local server for GPU availability on this server
